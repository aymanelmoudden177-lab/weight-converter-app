# Weight Converter – Android App

A native Android app built in Kotlin for the Mobile Web App Development module at the University of West London (2025/26).

## Features

- Converts between kilograms, pounds, stone and grams
- Converts every value to kilograms first, then to the target unit, so each unit needs only one conversion rule
- Safe input parsing with `toDoubleOrNull()` and Toast messages for empty or invalid input
- Clear button to reset the screen

## Tech stack

Kotlin, XML layouts, Android Studio

## Run it

1. Clone the repository
2. In Android Studio, open the `weight-converter-app` folder inside the repository
3. Let Gradle sync, then run it on an emulator or a physical Android device
